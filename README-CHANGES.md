# Орен Мрамор — изменения

Это улучшенный проект на Eleventy/Nunjucks. Исходники в `src/` — редактируйте их, а `public/` генерируется при сборке.

## Изменения
- Восстановлена страница `/catalog/` (раньше там по ошибке лежал JSON).
- Добавлены 9 категорий (страницы генерируются из `src/_data/categories.json`).
- Добавлена страница `/portfolio/` и 17 оптимизированных фотографий в `src/assets/img/`.
- Заменены отсутствующие ссылки на изображения на реальные файлы.
- Улучшены header/footer, мобильная навигация, главная страница, метатеги, sitemap, JSON-LD.
- Неподтверждённые суммы в новых карточках заменены на «по запросу»; калькулятор заменён на форму запроса расчёта.
- `/kladbishcha/` временно noindex, пока не готов контент.

## Важно перед публикацией
1. Сверить все контактные данные и расписание с владельцем компании.
2. Получить разрешение на публикацию фото с личными портретами, именами и датами. При необходимости замаскировать данные. Фото сейчас включены в портфолио как присланные заказчиком.
3. Фотографии в карточках каталога — иллюстрации выполненных работ, а не точные фотографии SKU. Заменить товарными фото до массового SEO-продвижения.
4. Сверить цены / модели с оригинальными карточками старого сайта. Не обещать конкретных гарантий и сроков без подтверждения.
5. Раздел отзывов временно noindex, так как источники исходных отзывов не подтверждены.
6. Настроить реальные 301-редиректы на сервере и проверить сохранение ценных старых URL.
7. На странице контактов оставлены прямые способы связи, без формы с неподключённым сервером.

## Команды
`npm ci` затем `npm run build` (для разработки `npm run dev`).
Если зависимости не установлены, потребуется подключение к npm registry.
